# ADR-003: ORM/SQLジェネレータの選定

## 1. 決定日

2025年12月23日

## 2. ステータス

提案 (Proposed)

## 3. 決定の背景

現在、プロジェクトではORMとして `sqlboiler` を利用している。
`sqlboiler` はGoのコードを自動生成し、型安全なORMとして機能するが、公式リポジトリがアーカイブされ、後継として `Bob` への移行が推奨されている。
この状況を受け、既存の`sqlboiler`からの移行先として`Bob`が最有力候補であるが、リフレクションを使わないコード生成ベースの有力なORM/SQLジェネレータ（`sqlc`など）も存在するため、多角的に比較検討を行い、最適なツールを選定する。
ORM選定においても、コンパイル時の型安全性やパフォーマンスを重視する。

## 4. 決定事項

ORM/SQLジェネレータとして `Bob` を採用する。

## 5. 決定理由

プロジェクトの要件と各候補ツールの比較検討の結果、`Bob` が最も適切であると判断した。

### 5.1. 要件への合致

* **コード生成ベース**: `Bob`はデータベーススキーマからGoコードを自動生成する。`sqlc`ライクなSQLからのコード生成も可能であり、この要件を完全に満たす。
* **コンパイル時安全性**: 生成されるORMコードおよびSQLコードは型安全であり、コンパイル時に多くのエラーを検出できる。
* **パフォーマンス**: 生成されるコードはリフレクションを使用せず、実行時のオーバーヘッドが少ない。
* **開発体験**: `sqlboiler`からの移行を前提として設計されているため、既存の開発者にとっては学習コストが低く、クエリビルダーとORMの両方を提供することで記述の柔軟性が高い。
* **メンテナンス性**: `sqlboiler`がアーカイブされたのに対し、`Bob`は活発に開発・メンテナンスされており、コミュニティも成長中である。

### 5.2. 各候補との比較

| 評価軸 | `sqlboiler` | `sqlc` | `Bob` | `ent` | `gorm` |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **アプローチ** | DB First | DB First | DB First | Code First | Code First |
| **コード生成** | ◎ (スキーマから) | ○ (SQLから) | ◎ (スキーマ/SQLから) | ◎ (Goコードから) | ✕ (リフレクション) |
| **実行時オーバーヘッド** | ほぼなし | ほぼなし | ほぼなし | ほぼなし | あり |
| **型安全性** | ◎ (コンパイル時) | ◎ (コンパイル時) | ◎ (コンパイル時) | ◎ (コンパイル時) | △ (実行時) |
| **クエリAPI** | クエリビルダー | SQL | クエリビルダー + SQL | グラフAPI | メソッドチェーン |
| **学習コスト** | 中 | 低 | 中〜高 | 高 | 低〜中 |
| **プロジェクト活発度**| 低 (アーカイブ) | 活発 | 活発 | 活発 | 活発 |
| **ORM機能** | ◎ | ✕ | ◎ | ◎ | ◎ |
| **マイグレーション** | ✕ | ✕ | ✕ | ◎ | △ |

### 5.3. その他の候補が不採用となった理由

*   **`sqlboiler`**: 公式に開発が停止しアーカイブされているため、長期的なプロジェクトの持続性を考慮すると代替が必要。
*   **`sqlc`**: 型安全なSQLクライアントとしては非常に優れているが、リレーションシップ管理などのフルORM機能を持たない。`sqlboiler`からの移行を考えると、機能不足の懸念がある。
*   **`gorm`**: リフレクションベースであり、プロジェクトの最重要要件である「コード生成ベースによるコンパイル時の安全性とパフォーマンス」を満たさないため不採用。
*   **`ent`**: 非常に優れたORMだが、スキーマをGoコードで定義する「コードファースト」のアプローチを取る。これは、DBスキーマ定義を正とする「データベースファースト」を基本方針とする本プロジェクトとは思想が合わないため不採用。

## 6. 懸念事項と対応策

現在のところ特筆すべき大きな懸念事項はないが、多機能ゆえに学習コストが`sqlc`より高くなる可能性は考慮する。
`sqlboiler`からの移行を支援するドキュメントやツールを活用し、円滑な移行を目指す。

## 7. 決定の結果

`Bob`の導入を進める。
