# ログ設計書

## 1. 目的

本APIサーバーが出力するログの仕様を定める。ログは以下の目的で利用する。

- **開発・デバッグ**: 開発時にアプリケーションの動作を詳細に追跡し、不具合の修正を効率化する。
- **障害調査**: 本番環境でエラーや予期せぬ事象が発生した際に、原因を迅速に特定する。
- **モニタリング**: ログを集計・可視化し、アプリケーションの稼働状況やパフォーマンス、エラーレートなどを監視する。

## 2. ロギングライブラリ

Go 1.21から標準ライブラリに組み込まれた `log/slog` を使用する。
サードパーティライブラリへの依存をなくし、標準的な方法で高性能な構造化ロギングを実現できる。

## 3. ログレベル

以下の4つのログレベルを定義する。

| レベル  | 説明                                                               |
| :------ | :----------------------------------------------------------------- |
| `DEBUG` | 開発時のデバッグにのみ使用する詳細な情報。変数の値など。             |
| `INFO`  | システムの正常な動作を示す情報。リクエストの受付、主要処理の開始/終了。 |
| `WARN`  | 直ちにエラーではないが、注意が必要な状況。非推奨APIの使用、リトライ可能なエラーなど。 |
| `ERROR` | 処理の続行が不可能なエラー。データベース接続断、パニックからの復旧など。 |

本番環境(`prod`)では`INFO`レベル以上、開発環境(`dev`)では`DEBUG`レベル以上のログを出力するよう設定する。

## 4. 構造化ログフォーマット

ログは**JSON形式**で標準出力に書き出す。これにより、CloudWatch LogsやDatadogなどのログ収集・分析サービスで容易にパースできる。

### 4.1. 基本フィールド

全てのログに共通で含めるフィールド。

| フィールド名  | データ型 | 説明                                |
| :------------ | :------- | :---------------------------------- |
| `time`        | string   | ログ出力時刻 (RFC3339形式)          |
| `level`       | string   | ログレベル (`INFO`, `ERROR`など)    |
| `msg`         | string   | ログのメインメッセージ              |

### 4.2. リクエストスコープフィールド

HTTPリクエストの処理中に記録するログに、可能な限り含めるフィールド。Ginのミドルウェアで`slog.Logger`に付与することを推奨する。

| フィールド名    | データ型 | 説明                                                                 |
| :-------------- | :------- | :------------------------------------------------------------------- |
| `trace_id`      | string   | リクエストを一意に識別するためのID。リクエストの処理全体で引き回す。   |
| `http.method`   | string   | HTTPリクエストメソッド (`GET`, `POST`など)                           |
| `http.path`     | string   | HTTPリクエストパス (`/api/v1/todos`)                                 |
| `http.status`   | int      | HTTPレスポンスのステータスコード (リクエスト完了時に記録)            |
| `http.latency`  | float    | リクエスト処理時間（秒） (リクエスト完了時に記録)                    |

### 4.3. エラーフィールド

`ERROR`レベルのログに含めるフィールド。

| フィールド名    | データ型 | 説明                                    |
| :-------------- | :------- | :-------------------------------------- |
| `error`         | string   | エラーメッセージ (`err.Error()`)        |
| `stack_trace`   | string   | エラー発生時のスタックトレース          |

## 5. ログ出力例

### 5.1. INFO: リクエスト完了ログ

```json
{
    "time": "2025-11-26T12:00:01.123Z",
    "level": "INFO",
    "msg": "Request Completed",
    "trace_id": "abc-123-xyz-789",
    "http.method": "GET",
    "http.path": "/api/v1/todos",
    "http.status": 200,
    "http.latency": 0.015
}
```

### 5.2. ERROR: データベースエラーログ

```json
{
    "time": "2025-11-26T12:00:02.456Z",
    "level": "ERROR",
    "msg": "Failed to create todo",
    "trace_id": "def-456-uvw-123",
    "http.method": "POST",
    "http.path": "/api/v1/todos",
    "error": "failed to connect to database: connection refused",
    "stack_trace": "goroutine 1 [running]:\nmain.main()\n\t/app/main.go:123 +0x12\n..."
}
```
